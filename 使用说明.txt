Thinka Excel Converter v1.5 开发测试版
=================================

【软件用途】
Excel 是批量添加设备的主要编辑界面；本软件负责读取、设备预览、少量修改、配件服务组合、校验和生成 Thinka CSV。
软件不自动推测 KNX 的灯光群控与分控关系，不擅自修改原有设备 UUID。

【基本操作】
1. 打开 EXE（或者双击“启动工具.cmd”）。
2. 在“文件操作”页点击“导入 Thinka CSV”，或直接把 CSV 文件拖进 CSV 按钮，然后点击“导出 Excel 配置文件”。也可把 XLSX 直接拖进 Excel 按钮。
3. 使用 Excel 批量复制、新增和修改设备行、名称、房间、KNX 读写组地址。
4. 对所有新复制的设备，请手动清空它们继承的旧 UUID。
5. 如果复制的是一个含多个服务的组合配件，新设备的“配件组号”也必须与原配件不同；同一新配件内的服务要使用相同的新组号。
6. 保存 Excel，点击“导入 Excel”或直接拖进 Excel 按钮；程序自动打开“设备预览与编辑”页。
7. 核对房间、设备、服务和组地址。如需改少量参数，可在右侧表格直接编辑。可组合服务、解除组合、撤销/重做、恢复设备。
8. 点击“导出 Thinka CSV”，检查弹出的警告并确认。只有文件被重新读取且内容与当前工作副本一致后才会保存为正式文件。
9. 如需把新 UUID 写回 Excel，手动再点击“导出 Excel 配置文件”。

【界面说明】
两个标签页：“文件操作”“设备预览与编辑”。
左侧设备树按房间和逻辑配件组织，右侧可编辑房间、服务名称、读取与写入 KNX 组地址；高级模式才允许直接修改 UUID。
组地址可输入 1 2 3 或 1 / 2 / 3，在编辑完成后规范化成 1/2/3。
软件默认不覆盖源文件，Ctrl+Z 撤销，Ctrl+Y 重做。退出时存在未导出修改会提醒。

【Excel 格式】
- 11 列 Thinka 字段改为中文表头，额外有“配件组号”和隐藏的“原始行序”。
- 数据列可以重新排序，支持新增自定义备注列，但必要的 11 个表头不可丢失或重复。
- 调整 Excel 时要移动整行，避免让某个特征/参数归属错误。
- “原始行序”是为了尽量保持原 CSV 的行序。复制整个数据行可能复制此标识，软件会将重复行序的后续记录放到末尾；复杂变化需要人工核对。
- 新增设备并不是只增加一个灯：一个服务可能由多条 characteristic 或 parameter 行组成，复制时要保留必要的整个服务配置。
- Excel 中的组地址必须保留为文本，不能被 Excel 转成日期。

【UUID 规则】
- 原有 UUID 保留；新复制设备需手动清空旧 UUID。
- 对同房间同组号的服务，导出 CSV 时使用同一个 UUID。
- 组内已有不同非空 UUID 时禁止导出；若组内既有 UUID 又有空白 UUID，将提示核对配件组号。
- 没有组号且 UUID 为空的独立服务，默认留空交 Thinka 生成。需要软件生成时，勾选文件页的相应选项。
- 配件组号是 Excel 编辑辅助字段，不出现在 Thinka CSV 中。

【输出与兼容性】
首次默认输出根目录：桌面\Thinka文件（不是固定路径）
可直接在顶部文本框输入任意有效绝对目录，点击“应用路径”或按 Enter；也可以“选择文件夹”或“恢复默认”。
成功设置后会记住该根目录，下次启动仍可继续使用。
Excel 文件：选定根目录\Excel配置文件
CSV 文件：选定根目录\Thinka导入文件
每次按“项目名_日期时间”创建新文件；原始文件不覆盖。
导出 CSV 固定 11 列英文表头，UTF-8 无 BOM。
Excel 读取和写入由 Open XML 完成，不依赖 Microsoft Excel COM、Python 或互联网。
支持 Windows 10/11 与 PowerShell 5.1，EXE 由 PS2EXE 生成。

【检测与安全】
文件操作页“全面检测”可以生成报告；导出时会阻止已知的结构和组地址错误。
成功生成 CSV 只说明通过本软件的静态与回读检查，不意味着 Thinka 必然接受。请先备份最初的 Thinka CSV，并用少量设备测试。
不要将客户工程 CSV、XLSX、真实 UUID 或 KNX 地址公开上传到 GitHub。

【版本说明】
本分支为 v1.5 开发测试版。v1.4.1 稳定版仍保存在 GitHub main/Release。
开发版现有自动测试：核心双向转换、Excel 复制新增、无效地址阻断、UUID 组合、列重排与自定义列保护，以及 Windows GUI 冒烟测试。
尚需真实 Thinka 导入与现场鼠标操作验证。
