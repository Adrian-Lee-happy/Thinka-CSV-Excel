Thinka Excel Converter v1.4.1 修复版
=================================

【v1.4.1 修复说明】
修复读取 XLSX 时提示“找不到 SelectSingleNode 的重载，参数计数为 2”的错误。问题来自 PowerShell 返回 XML 命名空间管理器时的自动枚举，非用户 Excel 数据损坏。

【此前的性能优化】
已去掉 v1.3 使用的 Excel COM 自动化。读写 XLSX 改为直接处理 Excel 使用的 Open XML (ZIP + XML) 文件格式，不再启动 Excel 程序，也不再逐个单元格调用 Excel。
原来的两个拖放窗口、配件组号与 UUID 规则、中文标题、文本保护、合规检查及输出目录均保持不变。
新增操作耗时显示与「运行自检.cmd」。

【运行要求】
Windows 10/11，使用系统自带的 Windows PowerShell 5.1。
软件转换、UUID 操作和检查均不依赖 Microsoft Excel；但要编辑生成的 XLSX，仍建议使用 Microsoft Excel 桌面版。
解压后双击「启动工具.cmd」。如窗口闪退，可以打开 PowerShell 查看错误信息。

【文件输出】
默认“当前用户桌面\Thinka文件”。可以选择其他目录，并自动记住。
左侧 Thinka CSV → 中文 XLSX，输出到“修改”文件夹。新增仅供编辑的首列「配件组号」。
右侧 中文 XLSX → Thinka CSV，输出到“thinka”文件夹，自动删除配件组号列并恢复原来的 11 列英文表头。
写出的 CSV 为 UTF-8 无 BOM（与之前的 Thinka 原始样本一致），绝不自动修改组地址或其他参数。
同名文件不会覆盖，自动增加编号。

【配件组号 / UUID】
• 一个组号仅在同一房间内有效，不同房间相同组号互不影响。
• 同一个服务的多行数据由“房间+服务名称+服务类型”识别，共用同一 UUID。
• 同一个配件的多个服务，例如“空调1 / Thermostat”与“空调1风速 / Fan”，填写同一组号，就会自动共享一个 UUID。只需在每个服务的一行填写组号。
• 没有组号、没有 UUID：默认保持为空，由 Thinka 自行生成。
• 已有 UUID：保留；如果组内多个 UUID 冲突，停止导出，不自动覆盖。
• 勾选“导出 CSV 时，为没有组号且没有 ID 的独立服务也生成 UUID”，可在导出时补齐所有独立服务 ID。
• 点击“生成全部 UUID Excel...”，会另外生成一份补齐 ID 的 XLSX，不修改原文件；尽可能保留原工作簿的排版及其他工作表。
• 自动生成新 UUID 后，还会另存“_已写入UUID.xlsx”供之后持续编辑，以免多次从旧文件生成不同 UUID。

【合规检查】
选择 CSV / XLSX，检查字段数量、标题、必填列、UUID 格式、多行参数 ID 冲突、组号冲突、同配件重复服务名称、KNX 组地址等。
生成的中文 TXT 报告保存在“检查报告”文件夹。
这里只是已知规则的静态校验，不保证 Thinka 一定接受某个特定服务或参数。

【速度与数据验证】
本版每次操作都会在窗口下方输出耗时（秒），可与 v1.3 的 30–60 秒对比。
首次使用，建议先双击「运行自检.cmd」。它会在 Windows 临时目录生成一套测试数据，并测试：
  1. CSV → Excel → CSV 的 11 列数据保持一致（包括中文和 KNX 组地址）。
  2. 普通设备多行共用 UUID，不同独立服务使用不同 UUID。
  3. 相同组号的多服务共用 UUID。
  4. 合规检查可生成报告。
自检成功时会显示“自检通过”，否则显示错误及调试文件目录。
注：本软件在非 Windows 环境开发、静态检查。实际 Windows 运行耗时、Excel 打开兼容性、Thinka 导入仍需你测试确认。

【注意】
1. 不要在 Excel 中直接双击编辑 Thinka 原始 CSV，先从左侧生成 XLSX，避免组地址被识别为日期。
2. 复制旧设备新增设备时，请清空新设备复制出来的旧 UUID，按需要填写配件组号。
3. 不要改变中文标题及列顺序；组地址和配件 ID 必须以文本保存，不要使用公式。
4. v1.2 的旧 11 列中文 Excel 仍可在右侧导回 CSV，但不支持「配件组号」辅助列。
5. UUID 已生成后，后续修改请以最新“_已写入UUID.xlsx”为基础，避免生成不一致的新 ID。
6. 建议先对少量新设备进行导入测试，并保留最初从 Thinka 导出的 CSV 作为备份。
